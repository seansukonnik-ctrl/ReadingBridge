Бэкап всех данных этого набора
🔗 Связь с расширением Chrome
Работает только если эта страница открыта через локальный сервер (http://localhost), не через двойной клик по файлу. ID расширения смотри в chrome://extensions (нужен Developer mode).
Как это работает вместе: все четыре инструмента используют один и тот же localStorage этого браузера — слово, добавленное в Reading Bridge, сразу видно в Прогрессе и Тон-тренажёре, а освоенные слова автоматически подпитывают Деревню.

Важно: это работает надёжно в Chrome при открытии файлов напрямую (двойным кликом). Если что-то не подхватывается между страницами — открой папку через локальный сервер: в терминале перейди в эту папку и запусти python3 -m http.server 8000, затем открой http://localhost:8000 в браузере. Так гарантированно все страницы будут в одном хранилище независимо от браузера.

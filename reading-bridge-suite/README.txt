Reading Bridge — локальный набор (standalone suite)
=====================================================

Что внутри:
- index.html          — стартовая страница со ссылками на всё
- reading-bridge.html — чтение с заменой слов на pinyin + звук
- dashboard.html       — прогресс по словарю + повторение почти забытого
- tone-trainer.html    — тренажёр на слух: тоны и значения
- village.html         — долгосрочная геймификация (деревня)

Как открыть
-----------
Проще всего: распакуй архив куда-нибудь постоянное и открой index.html
двойным кликом. В Chrome это должно работать надёжно — все страницы
из одной папки делят один и тот же localStorage (данные браузера),
так что слова, добавленные в Reading Bridge, сразу видны в остальных
инструментах.

Если данные почему-то не подхватываются между страницами (бывает в
некоторых браузерах при открытии файлов напрямую) — запусти локальный
сервер вместо прямого открытия файлов:

  1. Открой терминал / командную строку
  2. Перейди в папку с этими файлами (cd путь/к/папке)
  3. Запусти: python3 -m http.server 8000
     (если python3 не находится — попробуй просто "python")
  4. Открой в браузере: http://localhost:8000

Так гарантированно всё будет в одном хранилище независимо от браузера.

Важные ограничения по сравнению с версией внутри Claude
---------------------------------------------------------
- Кнопка автоперевода "⇄ Подобрать EN" в Reading Bridge здесь не
  работает — ей нужен доступ к API Claude, которого нет вне Claude.ai.
  Подбирай перевод в версии внутри Claude, потом переноси слово сюда
  вручную (английское слово + pinyin + иероглифы).
- Прогресс здесь никак не связан с прогрессом внутри артефактов Claude
  (это два разных хранилища). Если хочешь перенести данные оттуда —
  используй кнопку "Экспорт для деревни" в дашборде Claude и ручной
  импорт в village.html этого пакета.
- Звук (🔊) зависит от системных голосов text-to-speech. На Windows
  может понадобиться доустановить китайский голос через
  Settings → Time & Language → Language & region → китайский →
  Language options → Speech.

Бэкап
-----
На стартовой странице (index.html) теперь есть нормальные кнопки:
"💾 Скачать бэкап (.json)" — сохраняет все данные набора в файл,
"📂 Восстановить из файла" — загружает их обратно (в этом же браузере
или на другом компьютере). Никакой консоли не нужно.
